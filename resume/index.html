Aspect-Based Sentiment Analysis of Google Map Reviews (2026)

Capstone Project · Paper | GitHub

Compared classical NLP, transformer, and LLM approaches for aspect-level sentiment extraction across 22M+ real-world Google reviews.

  • Engineered 14 multi-label targets via weak supervision using star ratings as proxy labels (7 aspects x 2 sentiments) across 70.6M raw California reviews (25GB+).
  • Benchmarked TF-IDF + Logistic Regression baseline with negation handling and class weighting against fine-tuned RoBERTa and GPT-4.1-mini zero/few-shot prompting.
  • Found GPT-4.1-mini zero-shot outperformed all trained models on manually labeled ground truth (Weighted F1 0.757), while RoBERTa led on weakly labeled test set (Weighted F1 0.930), revealing noise inherent in weak supervision.
